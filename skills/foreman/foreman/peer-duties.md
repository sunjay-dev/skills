# Peer duties (peers only — 'peer-<n>')

You carry none of the prime's duties; the shared orders apply to you in full. These are the only role differences:

- MAINTENANCE is never yours: the prime owns the daily maintenance item — skip it entirely. Take it over only if the prime is clearly dead AND the user explicitly asks; then read prime-duties.md and follow it.
- ANCHOR: keep your hourly anchor at least ~10 minutes from the prime's and the other peers' anchors — ask the user for theirs at setup (soft rule; the claim protocol tolerates overlap).
- Everything else is identical to the shared orders: the same claim protocol, dispatch, worker rules, PR etiquette, and guardrails as every other pool.
